## 📘 Sobre o Projeto

Neste projeto, desenvolvi uma aplicação de lista de tarefas utilizando HTML, CSS e JavaScript com foco em **Programação Orientada a Objetos (POO)**.

O projeto foi desenvolvido de forma **totalmente solo**. A inteligência artificial foi utilizada **apenas para adicionar comentários explicativos no código**, facilitando o estudo e revisão de cada linha posteriormente — toda a lógica, estrutura e escrita do código foram feitos por mim.

---

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (ES6+ com POO)

---

## ✨ Funcionalidades

- Adicionar tarefas à lista
- Marcar tarefas como concluídas com indicação visual de texto riscado
- Remover tarefas da lista
- Scroll suave para a área de criação de tarefas
- Links para redes sociais no footer com ícones personalizados

---

## 🧠 Conceitos de POO Aplicados

- Classes (`Task` e `TaskList`)
- Constructor e inicialização de objetos
- Uso do `this` para referenciar o próprio objeto
- Métodos (`add()`, `remove()`, `finished()`)
- Instâncias com `new`
- Manipulação do DOM com JavaScript puro
